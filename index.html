🗄️ Supabase Database Configuration

Fetching current database status...

Connecting to your Supabase Project:
  1. Open your Supabase Project Dashboard and navigate to Project Settings → API.
  2. Copy the Project URL and anon public / service_role key.
  3. Set them in .env: 
    SUPABASE_URL=https://<your-project-ref>.supabase.co
SUPABASE_ANON_KEY=<your-key>
  4. Execute supabase/schema.sql in your Supabase SQL Editor.
  5. Run the migration CLI to verify: npm run migrate
